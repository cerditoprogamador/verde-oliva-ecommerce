## Las seis decisiones que definen todo

| Tema | Decisión |
|---|---|
| **Nombre** | Verde Oliva Olivoterapia |
| **Relación con el hotel** | Marca independiente. Usa el nombre y el origen como respaldo, no es "la tienda del hotel" |
| **Modelo comercial** | Apertura total: distribución amplia, exportación posible |
| **Catálogo** | 16 SKU de cosmética + Vallesi Arauco 500 ml. Sin vino |
| **Idiomas** | Bilingüe ES/EN desde el lanzamiento |
| **Registro** | Divulgativo y cálido, sin citas académicas — pero nunca impreciso |

## Sobre la exactitud de estos documentos

Todo dato sobre la finca, las personas, los productos, los formatos y los precios sale del sitio actual de Verde Oliva Casa de Huéspedes. No hay nada inventado en ese terreno.

Donde sí hay propuesta nuestra — nombres en inglés, arquitectura de líneas, packs, estructura del sitio, textos — está marcado como tal con el símbolo **⚑ A validar**. Revisá esos puntos antes de publicar.

## Una advertencia que conviene no saltear

La marca se para sobre el conocimiento. Eso es una ventaja y un riesgo: quien enseña queda expuesto a que le revisen lo que dice.

El aceite de oliva sobre la piel tiene beneficios reales y también límites reales. El documento [03 — Identidad verbal](03-identidad-verbal.md) incluye una lista de **afirmaciones prohibidas**. No es burocracia: es lo que separa a una marca con autoridad de una marca que se desarma ante la primera pregunta difícil.

Se escribe simple. Nunca impreciso.
